# Pizarra en vivo

Descargas de la app para Mac con chip Apple (M1 o más nuevo).

1. Bajá el `.dmg` de la [última versión](https://github.com/anegri93/pizarra-releases/releases/latest).
2. Abrilo y arrastrá «Pizarra en vivo» a Aplicaciones.
3. La primera vez, como no está firmada, macOS no la deja abrir: andá a Configuración → Privacidad y seguridad y
   tocá «Abrir igual».

Necesita Claude Code con tu cuenta. Si hay una versión nueva, la home de la app lo avisa.
